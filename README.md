# Nautanki's Birthday Microsite

A mobile-first static birthday microsite for GitHub Pages.

## Files

- `index.html`
- `images/hubble-ultra-deep-field.jpg`
- `images/pillars-of-creation.jpg`
- `images/fs-tau.jpg`
- `images/nebula-n159.jpg`
- `images/ic-758.jpg`

## GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and the entire `images` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. After GitHub deploys it, open the Pages URL on an iPhone in Safari and test the whole journey.

## Notes

The site is designed mobile-first for iPhone Safari, uses local Hubble images, and includes responsive layouts, safe-area handling, image preloading, cinematic Hubble screens, and a final cosmic birthday reveal.
